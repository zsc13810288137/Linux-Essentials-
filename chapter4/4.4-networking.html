你的计算机在网络中

本课命令：ip ping ss host dig

网络分层

层级作用
链路层直接相连的设备通信（MAC 地址）
网络层跨网络路由（IP 地址）
应用层程序之间通信（HTTP、SSH 等）
ip link show   # 查看网络接口和 MAC 地址

IPv4

32 位地址，写成四段十进制：192.168.0.1

子网掩码

IP = 网络部分 + 主机部分。子网掩码决定分割位置。

192.168.0.1/24 = 网络范围 192.168.0.0 ~ 192.168.0.255

私有地址（不能直接在公网路由）

地址段CIDR范围可用数量适合场景
10.x.x.x/810.0.0.0 ~ 10.255.255.255约 1677 万大型企业、数据中心
172.16~31.x.x/12172.16.0.0 ~ 172.31.255.255约 104 万中型企业
192.168.x.x/16192.168.0.0 ~ 192.168.255.255约 6.5 万家庭、小公司
快速判断：以 10. 开头 → 私有；以 192.168. 开头 → 私有；以 172. 开头且第二段 16~31 → 私有。其他基本都是公网。

配置 IP 与路由

# 添加 IP
sudo ip addr add 192.168.0.5/24 dev ens33

# 查看路由表
ip route show

# 添加默认网关
sudo ip route add default via 192.168.0.1

# 测试连通性
ping -c 3 192.168.0.1

IPv6

128 位地址，解决 IPv4 地址不足。写成 8 组 4 位十六进制：

2001:0db8:0000:abcd:0000:0000:0000:7334
# 简化为
2001:db8:0:abcd::7334
类型说明
全球唯一公网可路由
唯一本地（fc/fd 开头）类似 IPv4 私有地址
链路本地（fe80 开头）仅本链路有效

DNS

把域名转换成 IP 地址。

  • 配置文件：/etc/resolv.conf（指定 DNS 服务器）
  • 本地优先查询：/etc/hosts
host learning.lpi.org    # 简洁查询
dig learning.lpi.org     # 详细查询

DNS 记录类型

类型用途
A域名 → IPv4 地址
AAAA域名 → IPv6 地址
MX邮件服务器
CNAME别名（指向另一个域名）
TXT文本数据
PTR反向查询（IP → 域名）

套接字（Socket）

程序之间通信的端点，分三种：

类型特点适用场景
Unix Socket同一台机器，速度快、安全本地数据库、Docker
TCP可靠、有序、面向连接网页、SSH、文件传输
UDP不可靠、无连接、速度快视频、游戏、DNS

常见端口

端口服务
22SSH
80HTTP
443HTTPS
53DNS
3306MySQL

查看套接字

ss -t          # TCP 连接
ss -u          # UDP
ss -lnt        # 正在监听的 TCP 端口
ss -s          # 汇总信息
ss -tnp        # 显示进程信息
