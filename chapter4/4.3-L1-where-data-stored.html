Chapter 4 · Linux 操作系统

数据存储在哪里（FHS）

本课命令：which ls

一切皆文件

Linux 的核心理念：程序、目录、硬盘、键盘、进程、网络连接……都是文件。

程序存放位置

路径用途
/bin所有用户必需的基本命令（ls、mv、mkdir）
/sbin系统管理员必需的命令（ip、parted）
/usr/bin普通用户常用程序（free、ps、sudo）
/usr/sbin系统管理程序（useradd、groupadd）
/usr/local/bin本地编译安装的程序
/opt第三方可选软件
~/bin用户自己的程序
which nano   # 查找程序在哪里

配置文件

系统级：/etc

  • 无扩展名：passwd、shadow、hostname、hosts
  • .conf 结尾：resolv.conf、sysctl.conf
  • .d 目录：模块化配置（如 logrotate.d、apt/sources.list.d）

用户级：家目录隐藏文件

  • ~/.bashrc：非登录 shell 初始化
  • ~/.profile：登录 shell 初始化
  • ~/.bash_history：命令历史

内核文件：/boot

文件说明
vmlinuz-版本号压缩的可启动内核（vm=虚拟内存，z=压缩）
initrd.img-版本号启动时的临时根文件系统
config-版本号内核编译配置
grub/启动加载器配置

虚拟文件系统（不在硬盘上，内核动态生成）

目录作用
/proc运行中的进程、内核参数、硬件信息
/proc/cpuinfoCPU 详细信息
/proc/meminfo内存信息
/sys更有条理地展示硬件设备信息（sysfs）
/dev设备文件

特殊设备文件

文件作用用途
/dev/null黑洞，丢弃所有写入的数据丢弃不需要的输出
/dev/zero提供无限的空字符创建空文件、清空设备、性能测试
/dev/urandom生成伪随机数生成密码、密钥、随机数据
# 创建 100MB 空文件
dd if=/dev/zero of=test.img bs=1M count=100

# 生成随机文件
dd if=/dev/urandom of=random.bin bs=1M count=10

内存

  • 物理内存（RAM）：速度快但断电丢失
  • Swap：硬盘上的交换空间，内存不够时临时使用
  • 虚拟内存：应用程序看到的总可用内存（RAM + Swap）
