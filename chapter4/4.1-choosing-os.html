Chapter 4 · Linux 操作系统

选择操作系统

本课命令：uname

什么是操作系统

操作系统（OS）是计算机的核心，让应用程序能够运行，并提供驱动程序来访问硬件。

Linux 内核 vs 发行版

  • Linux 内核（Kernel）：所有发行版的核心，由 Linus Torvalds 领导维护
  • Linux 发行版 = 内核 + 各种软件、工具、桌面环境

发行版的三大类型

类型代表特点
企业级RHEL、SUSE Enterprise、Debian、Ubuntu LTS稳定、长期支持（RHEL 10年，Ubuntu LTS 5年），使用较旧但经过验证的内核
消费级Fedora、Ubuntu 非LTS、openSUSE使用较新内核和驱动，支持最新硬件，支持期短（约9个月）
实验性/极客Arch Linux、Gentoo滚动更新，软件最新，可能不稳定

Linux 的使用场景

  • 桌面：家庭/小公司免费且方便，常见桌面环境 GNOME、KDE
  • 服务器：企业中非常普遍，虚拟化和容器化后更是主流
  • 云：AWS、Google Cloud、Azure 等都提供多种 Linux 发行版

非 Linux 操作系统

系统说明
UNIXLinux 的灵感来源。商业版有 AIX、HP-UX；免费版有 FreeBSD、OpenBSD
macOS基于 BSD Unix，uname -s 显示 Darwin，命令行与 Linux 很像
Windows桌面市场占主导，服务器端也有纯命令行版本

内核版本号解读

以 6.17.0-1032-oem 为例：

部分含义
6主版本号（重大架构变化时增加）
17次版本号（功能增加、较大改进）
0修订号（小修复）
1032发行版自己的构建编号（补丁、定制）
oemOEM 定制标识，针对特定硬件优化的内核
uname -r     # 查看内核版本
