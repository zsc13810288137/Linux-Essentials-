Chapter 4 · Linux 操作系统

进程与系统日志

本课命令：top ps pstree uptime dmesg journalctl last

进程

每次执行命令都会产生进程。内核启动后先运行 systemd（PID=1），然后它启动其他进程，形成父子关系。

  • PID：进程自己的唯一编号
  • PPID：父进程的编号

动态查看：top

实时显示系统运行状态和所有进程。

快捷键功能
M按内存排序
P按 CPU 排序
N按 PID 排序
k杀死进程
W保存配置

推荐替代：htop（更友好）

静态查看：ps

ps            # 当前终端进程
ps -f          # 完整格式（含 PPID）
ps -uf         # 按用户显示父子关系
pstree         # 树状显示

系统负载

uptime
# 输出三个数字：过去 1分钟、5分钟、15分钟 的平均负载
# 含义：有多少进程在等待 CPU 或 I/O

系统日志

传统日志：/var/log/

文件内容
auth.log认证相关（登录、sudo、SSH）
kern.log内核相关
syslog系统综合信息
messages系统和应用程序

二进制日志需要专用命令：

文件查看命令内容
/var/log/wtmplast成功登录和重启记录
/var/log/btmplastb失败登录记录

内核环形缓冲区

dmesg              # 查看内核启动和硬件消息
dmesg -T           # 带时间戳
dmesg | grep -i sd  # 过滤硬盘相关信息

现代日志：systemd-journald

journalctl                    # 全部日志
journalctl -k                 # 内核消息（= dmesg）
journalctl -b                 # 本次启动的日志
journalctl -u ssh.service      # 某个服务的日志
journalctl -u nginx -n 50      # 最近50条
journalctl -f                  # 实时跟踪

运维常用场景速查

场景命令
系统是否刚重启过last reboot / uptime
硬件识别、驱动报错dmesg / journalctl -k
登录审计、暴力破解/var/log/auth.log 或 journalctl -u ssh
服务启动失败journalctl -u 服务名
磁盘问题dmesg | grep -i error
