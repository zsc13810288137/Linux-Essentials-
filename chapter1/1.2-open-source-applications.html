Chapter 1 · Linux 社区与职业

主要开源应用程序

本课命令：apt dnf dpkg rpm

软件包与包管理

发行版家族包格式常用命令
Debian / Ubuntu.debapt / apt-get / dpkg
Red Hat / Fedora.rpmdnf / yum / rpm
# 安装
sudo apt install figlet
sudo dnf install cowsay

# 删除
sudo apt remove figlet

# 彻底删除（含配置）
sudo apt purge figlet

办公套件

主流：LibreOffice（大多数发行版默认）和 Apache OpenOffice

组件功能对应
Writer文字处理Word
Calc电子表格Excel
Impress演示文稿PowerPoint
Draw矢量绘图—
Math公式编辑—
Base数据库Access

推荐使用 ODF（Open Document Format） 格式。

浏览器与邮件

  • Firefox：开源，Mozilla 基金会
  • Chrome：基于开源的 Chromium
  • Thunderbird：邮件客户端

多媒体应用

用途软件说明
3D 建模/动画Blender支持 3D 打印导出
位图编辑GIMP类似 Photoshop
矢量编辑Inkscape默认 SVG 格式
音频编辑Audacity多格式支持
命令行图像处理ImageMagick批量转换
视频播放VLC万能播放器

服务器程序

  • Web 服务器：Apache、Nginx、lighttpd
  • 数据库：MariaDB（源自 MySQL）、PostgreSQL
  • LAMP 组合：Linux + Apache + MySQL/MariaDB + PHP

数据共享与网络服务

  • NFS：Linux/Unix 之间共享
  • Samba：跨平台（Linux ↔ Windows）
  • ownCloud / Nextcloud：私有云方案
  • DHCP：自动分配 IP 地址
  • DNS：域名解析

编程语言

语言类型主要用途
C编译型系统级程序
Java编译型跨平台应用
JavaScript解释型网页前端/后端
Python解释型通用、数据科学
PHP解释型动态网页后端
Perl解释型文本处理
Shell解释型自动化脚本
