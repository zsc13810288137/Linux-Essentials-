Chapter 1 · Linux 社区与职业

Linux 的演进与流行操作系统

本课命令：ls uname

Linux 的起源

  • 1991 年由 Linus Torvalds 开始开发
  • 灵感来自 1970 年代 AT&T 开发的 Unix
  • 目标：为 x86 平台提供可负担的类 Unix 系统
  • 不含任何 Unix 代码，是独立项目
  • 由国际程序员社区共同维护，完全免费

发行版（Distributions）

发行版 = Linux 内核 + 精选应用程序 + 特定工具（安装、管理等）

主要发行版家族

家族包管理器代表发行版特点
Debiandpkg（deb）Debian GNU/Linux稳定可靠，坚持自由软件理念
Ubuntu2004 年创建，易用，每 6 个月发布，每 2 年一个 LTS
Red HatrpmRHEL企业级商业发行版，付费支持
CentOS基于 RHEL 源码重编译，完全免费
Fedora面向桌面，技术激进，RHEL 试验场
SUSESUSE Linux Enterprise商业版，适合企业
openSUSE社区版，提供 YaST 配置工具

特殊用途发行版

  • Kali Linux：渗透测试
  • QubesOS：高安全性桌面
  • 容器专用超轻量发行版
  • 嵌入式系统专用发行版

嵌入式系统中的 Linux

嵌入式系统 = 硬件 + 软件，控制更大系统中的特定功能。Linux 优势：跨厂商兼容、无授权费用。

Android

  • Google 基于修改后的 Linux 内核开发
  • 开源核心：AOSP（Android Open Source Project）
  • 扩展到电视、手表、游戏机、相机、PC

Raspberry Pi

  • 低成本、信用卡大小的计算机，最初用于教育
  • 配备 GPIO 引脚，ARM 处理器，从 SD 卡启动
  • Raspbian（现 Raspberry Pi OS）：基于 Debian 的专用发行版

Linux 与云计算

  • 90% 的公有云工作负载运行在 Linux 上（2017 年数据）
  • 通常以 IaaS 形式提供：选择含特定发行版的镜像，几分钟启动虚拟机
  • 所有主流云服务商（AWS、Google Cloud、Azure）都提供 Linux

练习要点

  • Debian vs Ubuntu：Ubuntu 更易用，Debian 更稳定
  • 选择发行版考虑因素：成本、性能、可扩展性、稳定性、硬件需求
  • 云计算优势：灵活扩展、易备份恢复、按需付费
