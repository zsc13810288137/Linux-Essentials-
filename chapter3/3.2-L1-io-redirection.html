Chapter 3 · 命令行的力量

I/O 重定向与管道

本课命令：cat head tail sort cut wc tr less find

标准通道

通道名称默认设备编号
标准输入stdin键盘0
标准输出stdout屏幕1
标准错误stderr屏幕2

输出重定向

# 标准输出
命令 > 文件          # 覆盖写入
命令 >> 文件        # 追加写入

# 标准错误
命令 2> 文件         # 只重定向错误（覆盖）
命令 2>> 文件       # 只重定向错误（追加）

# 同时重定向输出和错误
命令 &> 文件         # 覆盖
命令 &>> 文件       # 追加

# 丢弃不需要的输出
命令 2> /dev/null   # 把错误扔进"黑洞"

输入重定向

命令 < 文件          # 从文件读取输入，而不是键盘

# 示例：tr 不能直接接文件名，必须用 <
tr -d "l" < text    # 从 text 读取，删除所有字母 l

Here Document（<<）

直接在命令行输入多行内容：

cat << EOF
第一行
第二行
EOF

EOF 是自定义结束标记，内容不包含这个标记本身。

高级用法：在 Shell 中嵌入其他语言

# 直接运行 Python 代码
python3 << 'EOF'
print("Hello from Python!")
EOF

# 自动生成文件
cat << 'EOF' > test.py
def main():
    print("自动生成的脚本")
EOF

管道（Pipe）

把前一个命令的输出直接作为后一个命令的输入：

命令1 | 命令2 | 命令3

常用组合：

ls -l | head | wc -w               # 统计前10行的单词数
head -n 5 /etc/passwd | sort -r    # 取前5行并反向排序
find /usr/share -name test | wc -l # 统计文件数量
cat file | tr -s " " | cut -f 9 -d " " | sort -fr

重定向速查

符号含义场景
>标准输出覆盖保存命令结果到文件
>>标准输出追加追加日志
2>标准错误覆盖单独记录错误
&>全部输出覆盖同时捕获输出和错误
<标准输入重定向从文件喂数据给命令
<<Here Document内嵌多行文本
|管道串联多个命令
/dev/null黑洞丢弃不需要的输出
