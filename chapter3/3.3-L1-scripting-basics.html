Chapter 3 · 命令行的力量

脚本基础

本课命令：echo chmod bash

什么是脚本

把命令写进文件，加上可执行权限，让系统按顺序执行。Bash 既是 Shell，也是编程语言。

创建与运行脚本

# 创建脚本
echo 'echo "Hello World!"' > new_script

# 添加可执行权限
chmod +x new_script

# 运行（当前目录不在 PATH 中，必须用 ./）
./new_script

Shebang（#!）

脚本第一行指定解释器：

#!/bin/bash
# 这是注释，说明脚本用途
echo "Hello World!"
没有 shebang 时系统可能用当前 Shell 解释，行为不稳定。务必写上。

变量

# 赋值（等号两边不能有空格！）
username=Carol
username="Carol Smith"   # 带空格必须用引号

# 使用
echo $username
echo ${username}         # 花括号形式，更安全

引号区别

引号名称效果
" "弱引用会展开变量
' '强引用原样输出，不展开

位置参数

变量含义
$1 ~ $9第 1 到第 9 个参数
$#参数个数
$@ / $*所有参数
#!/bin/bash
echo "你传了 $# 个参数"
echo "第一个参数: $1"
echo "所有参数: $@"

条件判断（if）

if [ $# -eq 1 ]
then
  echo "Hello $1!"
else
  echo "请只传一个参数"
fi
方括号 [ ] 内侧必须有空格。结尾用 fi，不是 done。

数值比较运算符

运算符含义
-eq等于
-ne不等于
-gt大于
-ge大于等于
-lt小于
-le小于等于

字符串比较用 == 或 =。

常见错误

  • Shebang 写成 /!bin/bash → 正确是 #!/bin/bash
  • 变量赋值有空格 → 去掉空格
  • 方括号少空格 → [ $1 -gt $2 ]
  • 用 done 结束 if → 应该是 fi
  • 单引号导致变量不展开 → 改成双引号
