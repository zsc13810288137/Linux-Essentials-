Chapter 3 · 命令行的力量

命令行归档文件

本课命令：tar gzip gunzip bzip2 bunzip2 xz unxz zip unzip zcat

压缩的基本概念

  • 无损压缩（lossless）：可以完全还原（gzip、bzip2、xz）
  • 有损压缩（lossy）：无法完全还原（常用于图片、视频、音频）

核心思想：归档（打包）和压缩是两件事，经常一起使用。

常见压缩工具对比

工具扩展名特点解压命令
gzip.gz速度快，压缩率中等gunzip
bzip2.bz2压缩率较高，速度较慢bunzip2
xz.xz压缩率最高，速度最慢unxz
gzip file          # 压缩后变成 file.gz，原文件删除
gunzip file.gz     # 解压

bzip2 file
bunzip2 file.bz2

xz file
unxz file.xz

支持压缩级别（数字越大压缩率越高，速度越慢）：

gzip -1 file       # 最快
gzip -9 file       # 最高压缩

不解压直接查看内容：

zcat file.gz
bzcat file.bz2
xzcat file.xz

归档工具 tar（最重要）

tar 本身只负责打包，不压缩。常与压缩工具配合使用。

核心选项（必须记住）

选项含义
c创建归档
x解压/提取
t查看归档内容
f指定文件名
v显示详细过程
z使用 gzip 压缩
j使用 bzip2 压缩
J使用 xz 压缩
u向已有归档添加文件
P保留绝对路径

常用命令示例

# 创建并压缩（推荐）
tar czf archive.tar.gz 目录/     # gzip
tar cjf archive.tar.bz2 目录/    # bzip2
tar cJf archive.tar.xz 目录/     # xz

# 查看内容
tar tf archive.tar.gz

# 解压
tar xf archive.tar.gz
tar xvf archive.tar.gz           # 显示过程

# 只提取某个文件
tar xf archive.tar.gz 路径/文件名

# 通配符提取
tar xf tarfile.tar --wildcards dir/file*
注意：压缩后的 tar 包不能直接用 u 添加文件，必须先解压再操作。默认会去掉绝对路径开头的 /，防止覆盖系统文件。提取已存在的文件时会直接覆盖。

ZIP 文件（与 Windows 兼容）

# 创建（递归包含目录内容）
zip -r archive.zip 目录/

# 解压
unzip archive.zip

扩展名工具性质
