grep 与正则表达式

本课命令：grep

grep 命令基础

grep = "global regular expression print"，在文件中搜索指定模式并输出匹配行。

$ grep bash /etc/passwd
root:x:0:0:root:/root:/bin/bash
user:x:1001:1001:User,,,,:/home/user:/bin/bash

常用选项

选项含义
-i忽略大小写
-r递归搜索目录及子目录
-c只统计匹配的行数
-v反转匹配（输出不包含模式的行）
-E启用扩展正则表达式（支持 |、+、?）

正则表达式元字符

复杂模式务必用双引号 " " 包起来，防止 Shell 自己解释元字符。
元字符含义
.匹配任意单个字符（除换行）
[abc]匹配括号内任意一个字符
[^abc]匹配除括号内字符外的任意一个
[a-z]匹配范围内任意字符
sun|moon匹配 "sun" 或 "moon"（需 -E）
^行首
$行尾

乘数元字符（需 -E）

符号含义
*前面的模式出现 0 次或多次
+前面的模式出现 1 次或多次
?前面的模式出现 0 次或 1 次

实战示例

假设文件内容为：

aaabbb1
abab2
noone2
class1
alien2
$ grep "ab" text.txt          # 精确包含 "ab"
aaabbb1
abab2

$ grep "[ab]" text.txt        # 包含 a 或 b
aaabbb1
abab2
class1
alien2

$ grep "^a" text.txt          # 以 a 开头
aaabbb1
abab2
alien2

$ grep "2$" text.txt          # 以 2 结尾
abab2
noone2
alien2

$ grep -E "ab.+" text.txt     # ab 后面跟一个或多个任意字符
aaabbb1
abab2

管道 + grep

grep 不仅搜文件，还能过滤管道输入：

cat contents.txt | tr -s " " | grep "^....rwx"
# 查找组权限为 rwx 的行

练习要点

  • 包含 "cat"：grep "cat" file
  • 以任意 3 字母 + "dig" 开头：grep "^...dig" file
  • 以至少一个 e 结尾：grep -E "e+$" file
  • 包含 org、kay 或 tuna：grep -E "org|kay|tuna" file
  • 统计匹配行数：grep -cE "^c?ati" file
