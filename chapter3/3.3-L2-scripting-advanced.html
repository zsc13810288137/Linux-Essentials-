Chapter 3 · 命令行的力量

脚本进阶：退出码、循环与验证

本课命令：exit shift for grep

退出码（Exit Codes）

每个命令执行完返回一个退出码，存在 $? 里：

  • 0 = 成功
  • 非零 = 出错（不同数字可代表不同错误）
cat somefile.txt    # 成功
echo $?             # 0

cat noexist.txt     # 失败
echo $?             # 1

在脚本里用 exit 主动设置退出码：

if [ $# -eq 1 ]; then
  echo "Hello $1!"
  exit 0        # 成功
else
  echo "请只传一个参数"
  exit 1        # 失败
fi
echo "这行永远不会执行"  # exit 后脚本立即结束

for 循环

for username in $@
do
  echo "Hello $username!"
done

运行 ./script.sh Carol Dave Henry 输出：

Hello Carol!
Hello Dave!
Hello Henry!

shift 命令

把参数数组的第一个元素踢掉，剩余的往前挪：

# 参数: Carol Dave Henry
echo -n "Hello $1"   # 输出 "Hello Carol"（-n 不换行）
shift                # 现在 $@ = Dave Henry
for username in $@; do
  echo -n ", and $username"
done
echo "!"
# 最终: Hello Carol, and Dave, and Henry!

用 grep 做输入验证

核心思路：用 grep 匹配，然后检查 $?。

echo "Hello" | grep "^[A-Za-z]*$"   # 匹配成功 → $? = 0
echo "4n1ml" | grep "^[A-Za-z]*$"   # 匹配失败 → $? = 1

正则拆解：^[A-Za-z]*$ = 行首到行尾只有字母。

脚本中的用法：

for username in $@; do
  echo $username | grep "^[A-Za-z]*$" > /dev/null  # 抑制输出
  if [ $? -eq 1 ]; then
    echo "错误：名字只能包含字母"
    exit 2    # 用不同退出码区分不同错误
  else
    echo "Hello $username!"
  fi
done

综合示例：过滤大于 10 的数字

#!/bin/bash
for i in $@; do
  echo $i | grep "^[0-9]*$" > /dev/null  # 第一关：是纯数字？
  if [ $? -eq 0 ]; then
    if [ $i -gt 10 ]; then              # 第二关：大于 10？
      echo -n "$i "
    fi
  fi
done
echo ""
$ ./script.sh 5 abc 20 hello 3 42 100
20 42 100
为什么要先 grep 再比较？因为 [ hello -gt 10 ] 会报语法错误——-gt 只能比较数字。grep 那一步是"保镖"，把非数字参数提前挡在门外。
