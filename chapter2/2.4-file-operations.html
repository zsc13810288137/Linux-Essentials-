Chapter 2 · 在 Linux 系统中导航

创建、移动与删除文件

本课命令：mkdir touch echo cat mv cp rm rmdir find

大小写敏感

Linux 文件名区分大小写：/etc 和 /ETC 是不同路径。

创建目录

mkdir 目录名
mkdir -p 父目录/子目录       # 递归创建

创建文件

touch 文件名                 # 空文件
echo hello > question15      # 写入内容（⚠️ > 会覆盖！）
cat question15               # 查看内容

重命名与移动（mv）

mv 旧名 新名                 # 重命名
mv 文件1 文件2 目标目录       # 移动多个文件
mv -i 旧名 新名              # 覆盖前询问（推荐）

删除

命令作用说明
rm 文件删除文件
rmdir 目录删除空目录只能删空目录
rm -r 目录递归删除⚠️ 删除目录及所有内容
rm -ri递归删除并询问更安全

复制（cp）

cp 源文件 目标
cp -r 源目录 目标目录         # 复制目录必须加 -r

通配符（Globbing）

Shell 先展开通配符，再传给命令。

符号含义示例
*任意数量字符（含 0 个）star* → star10, star1100
?任意一个字符question? → question1
[abc]匹配其中任一字符file[1-3]
[^abc]匹配除指定字符外file[^a]
[[:digit:]]字符类file[[:digit:]]

用 \ 取消通配符特殊含义：ls star\*

实用选项

  • cp -p：保留权限和修改时间
  • mv -n：防止覆盖已有文件
  • cp -u：仅当目标不存在或比源旧时才复制
  • rmdir -p：递归删除空目录树
