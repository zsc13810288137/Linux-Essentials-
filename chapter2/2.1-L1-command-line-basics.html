命令提示符

格式：username@hostname current_directory shell_type

  • ~ = 家目录
  • $ = 普通用户
  • # = root 超级用户

命令行结构

command  [option(s)]  [argument(s)]
  • Command：要执行的程序（如 ls）
  • Option：修改命令行为（如 -l，长形式 --format=long）
  • Argument：额外数据（如路径 /home）

多选项可合并：ls -al = ls -a -l

内部命令 vs 外部命令

类型说明示例
内部命令（Builtin）Shell 自身内置，约 30 个cd、echo、exit
外部命令独立可执行文件，通过 PATH 查找man、ls
$ type echo     # echo is a shell builtin
$ type man      # man is /usr/bin/man

引用（Quoting）

类型效果
双引号 " "大部分特殊字符失效，但 $、\、` 仍有效
单引号 ' '所有特殊字符完全失效，原样输出
转义 \取消紧随其后一个字符的特殊含义
$ TWOWORDS="two words"
$ touch $TWOWORDS          # 创建两个文件：two 和 words
$ touch "$TWOWORDS"        # 创建一个文件：two words
$ touch '$TWOWORDS'        # 创建一个文件：$TWOWORDS

$ echo $USER               # 输出用户名
$ echo '$USER'             # 输出 $USER
$ echo \$USER              # 输出 $USER
建议：文件名避免空格，用下划线 _ 或点 . 代替。
