Chapter 2 · 在 Linux 系统中导航

变量（Variables）

本课命令：env echo export unset which

两种变量

类型特点
局部变量仅当前 Shell 可用，子进程无法访问
环境变量当前 Shell + 子进程都可用，通常大写
变量不持久，关闭 Shell 后丢失。需永久设置须写入配置文件。

基本操作

# 创建（= 前后不能有空格！）
greeting=hello

# 查看（必须用 $）
echo $greeting

# 删除（不加 $）
unset greeting

导出为环境变量

export greeting=hey

# 验证子进程可访问
bash -c 'echo $greeting'    # 输出 hey

# 临时为命令设置环境变量
TZ=EST date
TZ=GMT date

# 查看所有环境变量
env

PATH 变量

PATH 存储冒号 : 分隔的目录列表，Shell 在其中查找可执行命令。

echo $PATH

# 追加新目录（保留原有内容）
PATH=$PATH:/home/user/bin

# 查看命令实际路径
which nano    # /usr/bin/nano
注意：目录顺序决定查找顺序，第一个匹配的会被执行。
