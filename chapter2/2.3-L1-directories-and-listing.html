Chapter 2 · 在 Linux 系统中导航

使用目录与列出文件

本课命令：cd pwd ls mkdir tree

文件与目录

  • 文件：存放数据
  • 目录：组织文件和子目录
  • 文件名后缀在 Linux 中无特殊含义，仅方便识别
  • 避免文件名中使用空格和特殊字符

导航命令

pwd                          # 显示当前位置（绝对路径）
ls                           # 列出当前目录内容
ls -a                        # 包括隐藏文件
cd /home/user/Documents      # 切换目录

绝对路径 vs 相对路径

类型特点示例
绝对路径从 / 开始，任何位置可用/home/user/Documents
相对路径相对于当前位置Reports、../Documents

特殊路径

  • . — 当前目录
  • .. — 上级（父）目录
cd ..          # 回到上一级
cd ../..       # 连续向上两级
