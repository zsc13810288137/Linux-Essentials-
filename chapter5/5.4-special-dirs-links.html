特殊目录与文件链接

本课命令：ln ls

临时文件目录

目录重启后保留？用途
/tmp❌ 通常清空程序一次性临时文件
/var/tmp✅ 保留需要跨重启保留的临时文件
/run❌ 必须清空运行时数据（如 .pid 文件）

这些目录都是全局可写，靠 sticky bit 防止用户删除别人的文件。

链接

硬链接 vs 软链接

硬链接软链接（符号链接）
创建ln target linkln -s target link
本质同一个 inode 的另一个名字指向路径的"快捷方式"
删除原文件链接仍可用（数据还在）链接失效
跨文件系统❌ 不行✅ 可以
能链接目录❌ 不行✅ 可以
ls -l普通文件，链接计数+1l 类型，显示 → 目标
ls -i与原文件相同 inode不同 inode

创建示例

# 硬链接
ln original.txt hardlink

# 软链接（务必用绝对路径！）
ln -s /home/carol/Documents/original.txt softlink

# ❌ 相对路径，移动链接后会断
ln -s original.txt softlink
关键：创建软链接务必用绝对路径，否则移动链接后会断。软链接自身权限永远显示 rwxrwxrwx，但实际权限跟随目标文件。

陷阱示例

Documents/
├── clients.txt          # 内容: John, Michael, Bob
└── somedir/
    ├── clients.txt      # 内容: Bill, Luke, Karl
    └── partners.txt → clients.txt  # 相对路径！

把 partners.txt 移到 Documents/ 后，它指向的是 Documents/clients.txt（John, Michael, Bob），不是原来 somedir 里的那个！

比喻记忆

  • 硬链接 = 一个人有两个名字（中文名和英文名），叫哪个都找到同一个人。删掉一个名字，人还在。
  • 软链接 = 门上贴的纸条"去302房间找我"。如果302没了，纸条就没用了。但纸条可以贴在任何楼（跨文件系统）。
