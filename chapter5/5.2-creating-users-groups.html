Chapter 5 · 安全与文件权限

创建用户与组

本课命令：useradd userdel groupadd groupdel passwd

创建用户 useradd

sudo useradd -m frank     # 创建用户 + 家目录
sudo passwd frank          # 必须设密码才能登录
选项作用
-m创建家目录
-M不创建家目录
-d指定家目录路径
-s指定登录 Shell
-u指定 UID
-g指定主组（小写）
-G指定附加组（大写）
-c注释（全名等）
-e账户过期日期
# 完整示例：UID 6666，主组 GID 6666
sudo useradd -u 6666 -g 6666 -m satan
sudo passwd satan

删除用户

sudo userdel -r frank     # 删除用户及家目录

骨架目录 /etc/skel

-m 创建用户时，/etc/skel 的文件复制到新家目录。修改这里统一新用户默认配置。

组管理

sudo groupadd -g 1090 developer
sudo groupdel developer
创建用户前主组必须已存在。不能删除用户的主组。

密码管理 passwd

选项作用（仅root）
-l锁定账户
-u解锁
-d删除密码
-e强制下次修改密码
-S查看密码状态

passwd 设有 SUID 位，普通用户能修改自己密码。永远不要直接编辑 /etc/passwd 等文件。
