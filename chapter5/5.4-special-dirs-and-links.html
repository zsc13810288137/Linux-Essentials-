硬链接 vs 软链接

硬链接软链接
创建ln target linkln -s target link
本质同一 inode 另一个名字指向路径的快捷方式
删原文件链接仍可用链接失效
跨文件系统不行可以
链接目录不行可以
ls -i相同 inode不同 inode
# 硬链接
ln original.txt hardlink

# 软链接（务必用绝对路径！）
ln -s /home/carol/Documents/original.txt softlink
软链接自身权限永远 rwxrwxrwx，实际权限跟随目标文件。

记忆法

  • 硬链接 = 一个人两个名字，删一个名字人还在
  • 软链接 = 门上纸条"去302找我"，302没了纸条没用，但纸条可以贴任何楼

易错点

  • 相对路径创建的软链接，移动后可能指向错误文件
  • 链接计数 4 → 有 3 个硬链接指向同一数据
  • 跨文件系统硬链接报 Invalid cross-device link
  • 只有 x 没有 r：二进制可运行，shell 脚本不行
