Chapter 5 · 安全与文件权限

文件权限与所有权

本课命令：chmod chown chgrp ls groups

查看权限 ls -l

-rw-rw-r-- 1 carol carol 1881 text.txt
 ├──┤├──┤├──┤
  u   g   o

类型：- 普通、d 目录、l 软链接、b 块设备、c 字符设备

权限含义

权限文件目录八进制
r读内容列出文件名4
w修改/删除创建/删除/重命名2
x执行进入目录1
权限按 u→g→o 匹配，只应用第一个匹配到的。

修改权限 chmod

符号模式

chmod u+x file
chmod go-wx file
chmod u+rwx,g-x file

数字模式

chmod 754 file   # rwxr-xr-- (7=4+2+1, 5=4+1, 4=4)

口诀：421 对应 rwx，加法凑数。奇数必可执行。

修改所有权

chown carol:students file
chown :students file
chgrp students file

三个特殊权限

权限八进制符号作用
Sticky Bit1t目录中只有拥有者能删自己的文件（/tmp）
SGID2s(g)新文件继承组 / 以组权限运行
SUID4s(u)以所有者权限运行
chmod 1755 dir    # sticky
chmod 2755 dir    # SGID
chmod 4755 file   # SUID

大写 S/T = 特殊权限设了但 x 缺失

共享目录经典设置

mkdir Box && chown :users Box/ && chmod g+wxs,o+t Box/
# SGID + sticky：新文件属于 users 组，只有创建者能删

记忆法

  • r=透窗看 w=进去改装修 x=有钥匙进门
  • Sticky=公共储物柜只拿自己的 SUID/SGID=借工牌刷门禁
