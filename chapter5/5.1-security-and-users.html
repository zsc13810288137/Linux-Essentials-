Chapter 5 · 安全与文件权限

基础安全与用户类型

本课命令：id last who w su sudo chsh chfn

用户账户类型

类型UID 范围特点
超级用户 (root)永远是 0拥有系统全部权限，家目录 /root
普通用户≥ 1000有家目录、有登录 shell
系统账户< 1000系统预创建，通常无登录 shell
服务账户不固定为特定服务创建，无交互登录

关键配置文件

文件可读性作用
/etc/passwd所有人用户基本信息，不存密码
/etc/group所有人组信息（组名、GID、成员）
/etc/shadow仅 root密码单向哈希 + 策略
/etc/sudoers仅 rootsudo 授权（用 visudo 编辑）

/etc/passwd 格式

用户名:x:UID:GID:GECOS:家目录:Shell
emma:x:1000:1000:Emma Smith,42 Douglas St:/home/emma:/bin/bash

密码哈希

  • $1$ = MD5（已不安全）、$5$ = SHA-256、$6$ = SHA-512
  • !! = 账户被禁用

查看用户信息

id            # 当前用户 UID/GID/组
who           # 当前登录用户
w             # 更详细，含负载和进程
last          # 历史登录
lastb         # 失败登录

提权

su -          # 切换 root（加 - 用登录 shell）
sudo 命令     # 临时提权
chsh -s /bin/bash satan   # 改登录 shell
root 家目录在 /root 而非 /home，确保 /home 挂载失败时仍能修复。
